# PRUEBA-CONTRATO

Mapa de batalla entre provincias de España en un tablero hexagonal interactivo. Abre `index.html` en tu navegador para lanzar la simulación: cada batalla enfrenta dos provincias según su población, el ganador crece y absorbe las fronteras y el color del perdedor.

## Cómo usarlo

1. Abre el archivo `index.html` en tu navegador (no necesita servidor ni dependencias externas).
2. Pulsa **Elegir batalla** para lanzar una conquista o activa **Batallas automáticas**.
3. El panel derecho muestra la población acumulada, color y número de celdas de cada provincia.

Todo el mapa, efectos 3D suaves y datos de población están embebidos en el código para funcionar sin conexión.
